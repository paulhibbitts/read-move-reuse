## Courses

Free, open-source DIY tools for open textbooks, guides and courses – as five short courses from the same source. Not sure which? Start with the overview, [Open Textbooks, Guides and Courses](/guide).

**Read, Move, Reuse:** pages designed for every reader · your content goes wherever you go · you can always reuse your Markdown – and so can others, if you choose.

## Which course is for you?

- **[Open Textbooks, Guides and Courses](/guide)** – start here if you're not sure: the overview, for books and courses
- **[Open Textbooks and Guides](/open-publishing-space)** – for you if you write or share textbooks and guides
- **[Open Courses](/open-course-hub)** – for you if you teach or design courses
- **[Grav 2 for Open Education and Publishing](/grav-2)** – for you if you're choosing a platform
- **[Docsify for Open Education and Publishing](/docsify)** – for you if you'd rather not set up a web server

## Same courses, six sites

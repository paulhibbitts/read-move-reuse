## Home page

- Hook: share open content as web pages today, with just Markdown files and free hosting such as GitHub – no server, no install, no database
- What's in it: Docsify-This and the Docsify Starter Kits, plus a path to Grav when a project needs more

## 1. Why It Matters

- The problem: a server, a CMS or a build step stands between many educators and sharing their Markdown
- The Docsify answer: plain-text Markdown files, shown as web pages in the browser, with nothing to set up
- Read (any device, embedded in an LMS) · Move (to Grav and back, with a converter) · Reuse (the files are the source – fork and adapt)
- Honest framing: the lightest option, not the most capable

## 2. Docsify-This

- Any public Markdown file (GitHub, Codeberg, anywhere) as a styled web page, instantly – no signup, no install
- Several files make a multi-page site, with a sidebar and search
- Embeds in Canvas, Moodle, Brightspace or WordPress; point-and-click page builder
- Open Infrastructure Finalist, 2024 Open Education Awards for Excellence
- Live examples: one page · a whole guide (this one) · an embedded page

## 3. Docsify Starter Kits

- Your own site on GitHub Pages – your own domain and custom CSS, no coding needed
- Open Publishing Kit, Open Course Kit, Open MultiCourse Kit; Guide Site and Multiple Guides Site templates (covers, cards, Topics letter bar)
- When to choose a kit over Docsify-This: your own address, branding, a whole site in one repository
- Demos: the kit demo sites

## 4. Moving to Grav, and Back

- When a full site is worth it: browser editing with Admin 2, guides-only search, Keep My Place, a blog alongside
- Open Publishing Course Hub Converter: guides or a course between Docsify and Open Publishing Space or Open Course Hub, either direction, exact round trips
- Other ways in: Docsify Common Cartridge Converter (LMS courses); Pressbooks Converter's Standard Markdown option
- One link to the other guides for Grav itself – the only Grav part, to limit overlap

## 5. Which One Fits You?

- "I want to share one Markdown file or folder now" → Docsify-This
- "I want my own site on GitHub Pages" → a Starter Kit
- "I want browser editing and a full CMS" → Grav (the other guides)
- "I have a Pressbooks book or LMS course" → the converters
- Good to know: the Markdown needs a public home (such as GitHub); no Admin panel (edit in GitHub or an editor); search covers the current sidebar; no EPUB or formatted PDF (pages print from the browser); Markdown takes some getting used to

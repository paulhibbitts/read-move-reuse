**Free plugins**, for most Grav sites:

- **Mermaid** and **LaTeX Math** – diagrams and math written as plain text, like $E = mc^2$, or the diagram in [Meet Grav 2](/grav-2/meet-grav-2)
- **Admin2 Site ReadMe** – a site's own ReadMe in the Admin 2 sidebar, for whoever looks after it
- **Git Page Link** – an "Edit this Page" link back to a page's Markdown source

**Another free starter:** Learn2 with Git Sync – an open documentation site that others can help improve.

Want a premium look? [Grav Helios Open Reader](https://hibbittsdesign.org/grav-helios-open-reader.html?target=_blank) and [Grav Helios Course Hub](https://hibbittsdesign.org/grav-helios-course-hub.html?target=_blank) are counterparts built on Helios, a paid theme sold by the Grav team at getgrav.org – its sales help fund Grav CMS development.

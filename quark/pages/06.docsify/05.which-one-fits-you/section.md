Everything in this guide is **free and open-source**:

- **"I want to share a Markdown file or folder now"** → [Docsify-This](https://docsify-this.net/?target=_blank)
- **"I want my own site on GitHub Pages"** → a [Docsify Starter Kit](https://hibbittsdesign.org/docsify-starter-kits.html?target=_blank)
- **"I want browser editing and a full website"** → Grav – see [Open Textbooks, Guides and Courses](/guide)
- **"I already have a Pressbooks book or LMS course"** → the [Pressbooks](https://grav-pressbooks-converter.hibbittsdesign.org/?target=_blank) or [Common Cartridge](https://grav-common-cartridge-converter.hibbittsdesign.org/?target=_blank) Converter

[hideifembedded]

**Try it in 5 minutes:**

1. **Copy** the address of a Markdown file on GitHub – such as a README file in one of your own repositories
2. **Paste** it into the [Docsify-This Web Page Builder](https://docsify-this.net/?target=_blank) and choose a layout
3. **Share** the link it gives you, or embed the page in your LMS

[/hideifembedded]

> [!IMPORTANT]
> **Good to know:** your Markdown needs a public home, such as GitHub or Codeberg; there's no admin panel, so pages are edited on GitHub or in any text editor; search covers the pages in the current sidebar; pages load Docsify and its plugins from public services such as jsDelivr, so readers' browsers contact them too; there's no one-click ebook (EPUB or formatted PDF – pages print cleanly from the browser); a course home page doesn't update "This Week" by date the way Open Course Space does, so you edit it as the term goes on; and colleagues new to Markdown may need a little help to start.

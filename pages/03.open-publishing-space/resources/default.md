# Resources

Links for going further with Open Publishing Space, and with Markdown itself.

## The Project

- **Open Publishing Space 2** – demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/) or [several guides](https://demo.hibbittsdesign.org/grav-open-publishing-quark2-guides/) · [download](https://getgrav.org/downloads/skeletons#open-publishing-space-site) · [GitHub](https://github.com/hibbitts-design/grav-skeleton-open-publishing-space)
- **Pressbooks Converter** – [convert a book](https://pressbooks-converter.hibbittsdesign.org/) · [all converters](https://grav-converters.hibbittsdesign.org/)

## Writing in Markdown

- [What Is Markdown, and How Do You Use It?](https://www.howtogeek.com/448323/what-is-markdown-and-how-do-you-use-it/) – a friendly introduction (How-To Geek)
- [The Markdown Guide](https://www.markdownguide.org/) – a free reference
- [Markdown Cheatsheet](https://github.com/adam-p/markdown-here/wiki/Markdown-Cheatsheet) – the essentials on one page
- [Improving the Accessibility of Your Markdown](https://www.smashingmagazine.com/2021/09/improving-accessibility-of-markdown/) – headings, alt text and links (Smashing Magazine)
- [Getting Started with Writing and Formatting on GitHub](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github) – Markdown on GitHub
- [Authoring With Markdown](https://ucsbcarpentry.github.io/2022-01-31-ucsb-webpub-online/02-markdown/) – a workshop lesson (UCSB Carpentry)

## Markdown Editors

- [Visual Studio Code](https://code.visualstudio.com/) · [Pulsar](https://pulsar-edit.dev/) · [Typora](https://typora.io/) – desktop editors for writing Markdown files

## Learning More

- [Grav Learn](https://learn.getgrav.org/) – the documentation for Grav, the free CMS Open Publishing Space is built on
- [Cost-Free Grav Projects](https://hibbittsdesign.org/cost-free-grav-projects.html) – all four free starters, side by side
- [Leap into Open Publishing](https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/published-markdown-files/main&homepage=leap-into-open-publishing-standalone-guide.md&edit-link=https://github.com/paulhibbitts/published-markdown-files/blob/main/leap-into-open-publishing-standalone-guide.md&edit-link-text=View%20Source%20Markdown%20File&edit-link-emoji=:page_facing_up:&browser-tab-title=Leap%20into%20Open%20Publishing%20Guide&sidebar=true&searchbox=true&maxLevel=2&font-family=Open%20Sans,sans-serif&header-weight=600&dark-mode=auto#/?id=-additional-resources) – a short guide to open publishing, with more resources

## Other Options

- [Docsify-This](https://docsify-this.net/) – publish a Markdown file as a web page instantly, with no hosting needed
- [Grav Helios Open Reader](https://hibbittsdesign.org/grav-helios-open-reader.html) – a premium counterpart, built on the Grav Premium Helios theme

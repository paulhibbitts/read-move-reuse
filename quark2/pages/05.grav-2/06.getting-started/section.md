All the starters and converters in this guide are **free and open-source**, and you can explore the demos, try Admin 2 and try the converters with nothing to install:

- **"I want to share a textbook or guide"** → Open Publishing Space 2: demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/?target=_blank) or [several guides](https://demo.hibbittsdesign.org/grav-open-publishing-quark2-guides/?target=_blank) · [download](https://getgrav.org/downloads/skeletons?target=_blank#open-publishing-space-site)
- **"I want a web home for my course"** → Open Course Hub 2: [demo](https://demo.hibbittsdesign.org/grav-open-course-hub/?target=_blank) · [download](https://getgrav.org/downloads/skeletons?target=_blank#course-hub-site)
- **"I teach several courses"** → Open MultiCourse Hub 2: [demo](https://demo.hibbittsdesign.org/grav-open-multi-course-hub/?target=_blank) · [download](https://getgrav.org/downloads/skeletons?target=_blank#multicourse-hub-site)
- **"I want to start using Markdown, with no web server"** → [Docsify-This](https://docsify-this.net/?target=_blank) – free, with your Markdown files on GitHub or another public address; start from its [Guide Site](https://github.com/hibbitts-design/docsify-this-guide-site?target=_blank) or [Course Site](https://github.com/hibbitts-design/docsify-this-multiple-page-course-site?target=_blank) template, and the [Open Publishing Course Hub Converter](https://open-publishing-course-hub-converter.hibbittsdesign.org/?target=_blank) can turn it into a Grav site later – see the [Docsify for Open Education and Publishing](/docsify) guide
- **"I already have a Pressbooks book or LMS course"** → the [Pressbooks](https://pressbooks-converter.hibbittsdesign.org/?target=_blank) or [Common Cartridge](https://common-cartridge-converter.hibbittsdesign.org/?target=_blank) Converter

**Try it in 5 minutes:**

1. **Add** `.md` to this page's address to see its Markdown
2. **Press** ← and → to move through this guide, like slides
3. **Sign in** to [this site's read-only Admin 2 demo](https://try.hibbittsdesign.org/read-move-reuse/admin?target=_blank) and open a page – such as this one – to see its Markdown
4. **Compare** [a Pressbooks book](https://ecampusontario.pressbooks.pub/universaldesign2/?target=_blank) with [the same book in Open Publishing Space](https://demo.hibbittsdesign.org/grav-open-publishing-quark2-pressbooks-udl/?target=_blank), converted with no revisions

Then set up your own site:

1. **Download** a starter skeleton from [getgrav.org](https://getgrav.org/downloads/skeletons?target=_blank)
2. **Upload** it to your web host and unzip it (your host's file manager can do this), then open the site
3. **Open** Admin 2 by adding `/admin` to the site's address, set up your account and start writing

**Where to host:** many institutions offer web space for staff and students (often called a Domain of One's Own), and most low-cost web hosts run PHP 8.3 or newer.

> [!IMPORTANT]
> **Good to know:**
>
> - You'll need a PHP web host (PHP 8.3 or newer, no database), and you – or your host – look after the site's updates and backups
> - Editing is in Markdown – quick to learn, but not a word processor, so some colleagues may need a little help to start (the premium Editor Pro plugin shows formatted text instead)
> - An open course site works alongside your LMS rather than replacing it – there are no grades, quizzes or enrolment
> - Some Grav 1.7 plugins and themes aren't updated for Grav 2 yet
> - There's no one-click import from WordPress – existing pages need converting to Markdown ([the usual route](https://getgrav.org/blog/grav-vs-wordpress?target=_blank))
> - There's no one-click ebook (EPUB or formatted PDF) – pages print cleanly from the browser
> - Grav extras like definition and objectives boxes are shortcodes that other tools would need converted

description: 'Terms used in this guide, from CC BY 4.0 to shortcodes.'
glossary:
  - term: 'CC BY 4.0'
    definition: 'A Creative Commons licence that lets anyone share and adapt a work, for any purpose, as long as they give credit.'
  - term: 'Common Cartridge'
    definition: 'A standard file format for moving a course between learning management systems – Canvas, Moodle, Brightspace and Blackboard can all export one.'
  - term: Grav
    definition: 'A free, open-source website system that keeps every page as a Markdown file, with no database. Both starters in this guide are built on it.'
  - term: Markdown
    definition: 'A simple text format for web pages – `**bold**`, `## Heading`, `- list item` – supported almost everywhere, from GitHub to note-taking apps.'
  - term: OER
    definition: 'Open Educational Resources: teaching, learning and research materials that are free to use and openly licensed, so others can keep, adapt and share them.'
  - term: PHP
    definition: 'The programming language Grav runs on. Most web hosts include it.'
  - term: Pressbooks
    definition: 'A book publishing platform built on WordPress, widely used for open textbooks.'
  - term: Shortcode
    definition: 'A short tag in square brackets that Grav turns into a box, an embed or another feature when it shows a page.'

# Getting Started

All the starters and converters in this course are **free and open-source**, and you can explore the demo and try the converter with nothing to install:

- **"I want to share an open textbook or guide"** → Open Publishing Space 2: demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/) or [several guides](https://demo.hibbittsdesign.org/grav-open-publishing-quark2-guides/) · [download](https://getgrav.org/downloads/skeletons#open-publishing-space-site)
- **"I already have a Pressbooks book"** → the [Pressbooks Converter](https://pressbooks-converter.hibbittsdesign.org/)
- **"I want to start using Markdown, with no web server"** → [Docsify-This](https://docsify-this.net/), then the [Open Publishing Course Hub Converter](https://open-publishing-course-hub-converter.hibbittsdesign.org/) when you're ready for a full site – see [these guides on Docsify-This](https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-open-publishing-space-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&collapsibleSidebarGroups=true&pagination=true&searchbox=true&name=Open%20Publishing%20Space%20Guides), or the [Docsify for Open Education and Publishing](/docsify) guide
- **"I teach a course"** → its twin, Open Course Hub 2 – see the [Open Courses](/open-course-hub) course

**Try it in 5 minutes:**

1. **Add** `.md` to this page's address to see its Markdown
2. **Press** ← and → to move through this course, like slides
3. **Add** `?embedded=true` to this page's address to see it as it would appear in your LMS
4. **Sign in** to the [read-only Admin 2 demo](https://try.hibbittsdesign.org/grav-skeleton-open-publishing-space/admin?target=_blank) and open a page to see its Markdown

[/hideifembedded]

**See it moved:** this same course also runs, with the same content, as an Open Publishing Space guide on the [Quark 2](https://read-move-reuse.hibbittsdesign.org/open-publishing-space?target=_blank) and [classic Quark](https://one.on-rev.com/grav/read-move-reuse-ops-quark/open-publishing-space?target=_blank) themes, as an [Open MultiCourse Hub course](https://one.on-rev.com/grav/read-move-reuse-mch/open-publishing-space?target=_blank), and on Grav Premium Helios as an [open reader](https://one.on-rev.com/grav/read-move-reuse-hor/open-publishing-space?target=_blank) – and as plain Markdown pages on [Docsify-This](https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-read-move-reuse-site/main&homepage=home.md&name=Read%2C%20Move%2C%20Reuse&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&pagination=true&searchbox=true&dark-mode=auto&loadFavicon=favicon.png&target=_blank).

> [!IMPORTANT]
> **Good to know:** this web-first approach keeps things simple, but there's no built-in ebook generation (EPUB or formatted PDF – pages print cleanly from the browser), you'll need a PHP web host (PHP 8.3 or newer, no database), and Grav extras like definition and objectives boxes are shortcodes that other tools would need converted.

With thanks to the authors of the openly licensed book used as an example, for sharing their work in the open 🙏🏻
